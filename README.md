# 天空岛 · SKYE ISLAND

治愈系微缩海岛咖啡馆，含可部署静态游戏与有效开发源码。

## 目录与运行

- `app/src/`：当前有效 TypeScript 源码、模型与水彩素材。
- `app/public/music/`：默认音乐与环境音资源。
- `game/`：完整生产构建。根 `index.html` 自动进入 `game/index.html`。
- `docs/`：产品规格、阶段计划和实现记录。
- `PACKAGE-CHECK.json`：本次交付基线、文件校验和及验证结果。

开发使用 Node.js 22.12 或更高版本，运行 `npm ci`、`npm run dev`。运行 `npm run build` 执行 TypeScript 检查并生成 `game/`，同时复制静态文件至 `dist/`。不要在根目录旧 `src/` 中开发。

已有 GitHub Pages 设置继续沿用：分支静态发布使用根入口及 `game/`；现有 Actions 工作流会从 `app/` 源码重新构建。不要只上传 ZIP，也不要增加外层目录。游戏需要通过 HTTP/HTTPS 访问，并需要 WebGL 2。

## 当前内容

- 阿禾、林伯、棠姨原有故事与人物委托，Mona 独立彩蛋及隐藏饮品。
- 菜单制作售出或入库，仓库、花园种植与食材库存、装饰摆放及氛围小费。
- 水彩人物手记、轻量玩家界面、场景提示、手机适配与自由环绕观察。
- 晴雨雪、日光与暮色、音乐环境音、留影、室内与花园近景。
- 月牙形海岛、内湾港口与三艘小船、三块自然扩建预留地、近岸高脚屋、沙滩家具与餐车。
- 咖啡馆铺装与沙地缓坡衔接。默认仍以咖啡馆为中心，全岛机位显示月牙轮廓。

本地存档属于浏览器和域名。保持原地址可继续沿用既有存档；更换地址前可先导出，之后导入。包内没有玩家私人存档。声音可能需要首次用户点击后启用。

长期产品规格见 `docs/GAMEPLAY-CLOSURE-SPEC.md`，阶段记录见 `docs/GAMEPLAY-CLOSURE-PLAN.md`；月牙岛改造记录见 `docs/CRESCENT-ISLAND-REBUILD.md`。文档提及的本地截图、测试脚本和中间文件未作为运行文件随包交付。
