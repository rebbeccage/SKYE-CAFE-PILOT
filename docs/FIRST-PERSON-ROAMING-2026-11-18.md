# 可选步行漫游 · 2026-11-18

## 产品范围与保留项

按本轮用户补充，第一人称是**新增模式**，不是替换原视角。首次加载继续使用原正交环绕镜头、原默认位置与缩放；原花园近景、全岛概览、自动环绕、店内、沙滩坐席和电影院继续保留。

入口在「随心逛逛 → 步行漫游」。按钮再次点击为「返回环绕」。步行位置和朝向只保存在本次页面运行内，切换概览、人物面板、室内或坐席不会重置；不增加存档字段。刷新仍默认原环绕。

原人物剧情、委托、菜单、八秒制作、仓库、种植、装饰、经济和存档代码没有改写。

## 操作

- WASD：沿视线方向行走；Shift：稍快行走；E：面前近距离互动；R：平视。
- 点击场景申请 Pointer Lock。Esc 释放；浏览器拒绝时回退为按住拖动观察。
- 1：原全岛概览；2：返回步行。漫游中 Tab 打开/关闭「随心逛逛」。
- 打开原菜单、人物卡、对话、仓库、花园或帮助后暂停移动并释放鼠标。关闭后留在原地，不自动锁定。
- 手机：左侧摇杆，右侧空白区域拖动，互动按钮，双指微调 FOV；支持横竖屏。
- 原环绕模式中的花园按钮仍进入原近景；漫游中的花园入口及水上屋/港口/影院按钮仅提供方向与距离，不传送玩家。
- 咖啡屋门口可 E 或点选进入原室内，离开后恢复户外步行位置。影院和沙滩座位从附近主动互动，起身恢复原地。

## 实现

新增：

- `app/src/first-person-controller.ts`：输入、Pointer Lock/拖动回退、FOV、碰撞体与视线枢轴。渲染相机复制枢轴世界变换，兼容现有水面反射代码。
- `app/src/player-collision.ts`：半径 0.27m 运动学圆柱、滑动、阶梯/坡度限制、局部安全位置恢复。指数速度积分，不依赖显示帧率。
- `app/src/navigation-zones.ts`：采样现有沙地、石铺装、草径、港口和水上屋甲板；共享现有实际栈道诊断数据，不创建新地形。
- `app/src/interaction-raycast.ts`：摄像机中心射线、对象距离、玻璃/墙体遮挡。低矮作物按水平可及距离判断，避免眼高造成无法互动。
- `app/src/first-person-ui.ts`、`.css`：轻定位点、互动文案、方向指引、触摸摇杆。

接入修改：

- `app/src/main.ts`：互斥控制器、模式往返、原交互分发、简化动态人物碰撞、QA 只在 `?qa=1` 提供的输入接口。
- `app/src/scene-hint-model.ts`、`app/index.html`：补充实际移动操作，保留原任务数据来源。
- `app/src/music.ts`：复用现有声音开关、音量和 AudioContext，增加轻脚步、近岸/花园/港口/影院音量过渡及店外轻量馆内音乐渗透。
- `app/src/weather.ts`：仅为同一雨粒子系统增加可选漫游采样中心；原环绕和店内走原分支，湿润颜色、雨滴数、天气状态不变。
- `app/src/stilt-houses.ts`：用户明确同意后，第三座房屋前补约 2.3m 的带支撑短连接及栏杆开口。房屋、原岛体和其他对象位置不变；雪层沿用现有构造函数。

镜头默认 FOV 60°，可调 52–68°；眼高 1.6m，near 0.04，far 2000；俯仰上 55°/下 40°；正常 2.2m/s、稍快 3.2m/s，后退 75%、横移 85%，对角归一化；加速/减速时间常数 0.19/0.23s。无跳跃、镜头摇晃或新增后处理。

## 栈道与碰撞依据

咖啡馆室外石面约 +0.26m，室内 +0.85m，原入口坡面与两级台阶仍按已有坐标采样；主港口 BOARD_X=-3.5，起点/长度引用 BOARD_LAYOUT；水上屋甲板 +0.08m，支路直接引用既有 walkSegments。

花园草径引用 `garden-path.ts` 与花境相同的距离场。几何检查用实际每 15mm 最大运动子步验证连接，防止粗网格跨过狭窄不可行走区。临海范围只允许安全干沙或受支撑甲板，不允许从栈道侧面走入水中。

第三座屋前原主栈道擦过墙角，不能在不穿墙的情况下容纳玩家。用户批准的短连接位于旧岸端末段与第三座露台之间，仍由现有木桩/木板/积雪模块生成，没有移动房屋。

## 验证资料

本轮证据集中在 `verification/first-person/`，脚本：

- `first-person-unit.cjs`：30/60/144Hz 一致速度、相对移动、对角归一化、碰撞滑动、岸线/窄栈道边界、150mm 自动跨步、安全恢复。
- `first-person-ray.cjs`：最近目标、距离、未开放入口、玻璃阻挡、低矮作物可及性。
- `first-person-routes.cjs`：真实高度和简化碰撞下，连续到达草径、棠姨、两种作物、影院、主码头末端/支路、三座屋子。
- `first-person-browser.cjs`：默认仍环绕、可选漫游、真实 WASD、原地暂停、概览返回、门口进入、阿禾剧情、原花园近景。
- `first-person-mobile.cjs`：390×844 与 844×390 触摸摇杆/观察、导航不重叠、菜单暂停。
- `first-person-walk.cjs`：用同一个控制器实际逐帧步行与拍照，不通过更改玩家坐标传送。

原规则回归记录在 `regressions.json` / `.log`：人物委托、256 种旧存档迁移、花园、经营小费、仓库、Mona、场景提示、HUD。原始九章对话/回应、四款基础菜单和六件装饰继续逐字断言。旧“全部文件字节锁定”测试仅将本轮授权的雨粒子视点适配加入可变场景模块名单，业务断言未放宽。

生产构建使用 `npm run build`，仍有既有的大 JS chunk 提示，不是构建错误。浏览器手机测试是触摸模拟，不代表所有实体手机的帧率；本轮没有降低现有像素比、材质或场景模型精度，也没有新增实时灯光/反射通道。

## 最终验收记录

- TypeScript `--noEmit` 与生产构建通过；`game/`、`dist/` 已同步生成。
- 运动学 7 项检查通过，30/60/144Hz 五秒行程差小于 1e-9m；射线的距离、最近目标、权限、遮墙与低矮作物检查通过。
- 13 个目的地在真实地形与同一碰撞算法下连续可达，包含三座高脚屋、港口末端/支路、花园人物与两种作物。
- Chrome 实际逐帧输入走通三座高脚屋、影院和港口；高脚屋门前 E 显示未开放提示。影院观影与沙滩赏海均可起身回到原步行位置。
- 桌面默认环绕 → 漫游 → 概览 → 原地返回、WASD、面板暂停、入店与阿禾对话、原花园近景通过。
- 手机模拟 390×844、844×390：摇杆移动、右侧拖动、双指 FOV、菜单暂停、触控防误触及底部导航间距通过。
- 9 组规则回归全部通过，包含人物委托、花园、经济、仓库、Mona、场景提示与 HUD；旧存档迁移及原始内容锁定断言通过。
- 走访地点的晴/雨/雪切换保持第一人称模式，场景动画继续运行；暮色观影可正常启用。
- 浏览器验证未记录新增错误。

本轮额外修复两处输入边界：收起「随心逛逛」后的焦点不再截获全局 Esc；关闭面板后即使处于拖动回退，也必须重新点击场景才接受 WASD。双指操作结束不会顺带点中场景热点。

性能记录见 `browser.json`：同一构建的默认环绕采样约 51fps / 883 draw calls / 3,737,947 triangles，漫游入口约 61fps / 478 calls / 3,282,885 triangles，门前约 63fps / 417 calls / 4,501,100 triangles。不同视角可见对象不同，这些是运行采样，不是严格同视角前后性能对照；浏览器帧计数也不代表实体手机测量。新增控制器不降低原画质，不新增光源或后处理。

自动化 Chrome 使用了 Pointer Lock 拒绝后的拖动回退；真实用户手势下的原生 Pointer Lock 路径已接入，但不能把无头浏览器结果当作所有桌面浏览器的原生锁定兼容性认证。
