# 花园盛花与草径精修 · 2026-11-17

## 实际范围

当前开发入口 `app/src/`；修改生产构建已生成到 `game/`，预览 http://127.0.0.1:5194/ 。未发布、推送、修改用户存档。

### 审计与复用

- 沿用现有左侧花园台座、石边、连续草皮、微地形和全部植物/人物坐标。
- 保留5株尤加利、原有伴生草花、两只花箱、园艺桌与桌上水壶、倒扣陶盆、工具、橘白猫、灯串。
- 棠姨仍在世界坐标 (-6.8, .26, 2.65)，莫娜仍沿 x=-5.8、z=3.05…3.85 的既有走廊活动。
- 葡萄/草莓原模型、成熟果实显隐、种植射线热点、种植状态机全部复用。
- 原草坪缺少覆盖全园的游走线，原花形主要为零星白花/紫穗；本轮补充草径视觉与成簇花境，不重造场景。

## 实际修改

- `app/src/garden-path.ts`（新）：共享的草径与保留区坐标，仅用于草色/植被排除，不新增角色导航或碰撞系统。
- `app/src/garden-bloom.ts`（新）：五类共享花形与实例化花丛。奶油小雏菊、珊瑚玫瑰波斯菊、蓝紫绣球状花簇、杏黄金盏花、少量淡紫花穗；绿色间隔、花苞和细微倾斜。现有盆与水壶不重复添加，另加一块草边旧石和14片低对比落瓣。
- `app/src/garden-lawn.ts`：原有磨损/积雪遮罩改为共享连续草径，保留草色与短草；暴露相同地面采样函数用于花根贴地。
- `app/src/garden.ts`：创建花境，并连接既有 time / snow / rain 更新与 QA 诊断。
- `app/src/mona.ts`：彩蛋完成后的常驻“莫娜 · 歇一会儿”按钮隐藏；首次事件的“莫娜 · 聊聊”及模型射线点击、独立事件状态保持可用。
- 验证文件：新增 `garden-bloom-capture.cjs`、`garden-bloom-geometry.cjs`、`garden-bloom-interaction.cjs`；调整 `mona-playtest.cjs` 以从场景点击已完成事件的莫娜；旧 `quest-progression.cjs` 的不可修改文件列表明确排除本轮授权修改的草坪，新增范围校验仍冻结其他全部旧源码。

草径宽约0.86–0.96m，连接入口、两位人物停留区、园艺桌和作物区；花朵按花冠半径避开道路、人物走廊、猫、家具和作物。桌面291个花形实例（其中绣球为复合花头），手机190个；高花穗仅16/10个。

花境沿用现有哑光光照，不新增灯光、后处理、反射或监听器。统一局部风向与原草坪一致，花簇错相摆动；雨天压暗/降饱和、摆幅降至35%；雪天新增花境与落瓣收起，原草坪、草尖积雪和原有冬态继续运行。

## 性能实测

首轮花瓣原型约41.4万三角/单通道，精简至桌面15.1万、手机8.4万。新增模块固定7个批次（5种花、旧石、落瓣），雪天0批次；不投射额外阴影。下面为同浏览器设置、相同近景的90帧采样，渲染器数据包含现有多通道，因此不是模型独立统计：

| 环境 | 天气 | 绘制次数 前→后 | 三角形 前→后 | 中位帧间隔ms 前→后 | P95 ms 前→后 |
|---|---|---|---|---|---|
| 1440px 桌面 | sun | 880 → 897 | 6.071M → 6.381M | 16.7 → 16.7 | 16.8 → 17.3 |
| 1440px 桌面 | rain | 303 → 327 | 3.403M → 3.713M | 16.7 → 16.7 | 16.8 → 17.4 |
| 1440px 桌面 | snow | 445 → 445 | 4.976M → 4.915M | 16.7 → 16.7 | 33.3 → 33.8 |
| 390px 手机模拟 | sun | 811 → 825 | 5.557M → 5.709M | 16.7 → 10.0 | 16.8 → 10.4 |
| 390px 手机模拟 | rain | 282 → 298 | 2.949M → 3.131M | 16.7 → 10.0 | 16.9 → 10.4 |
| 390px 手机模拟 | snow | 425 → 423 | 4.366M → 4.359M | 16.7 → 10.0 | 16.8 → 10.2 |

桌面晴天平均三角形约增加5.1%，中位帧间隔保持16.7ms。手机模拟采样刷新节奏前后不同（16.7/10ms），不能据此声称手机变快；它也不能替代实机帧率。未发现明显帧时退化。原始数据与截图存放于 `verification/garden-bloom/`。
