# 水彩岛屿地图与步行动线

## 本次设计与资源
以当前海岸函数、建筑坐标和栈道生成布局参考，再依照用户附件重绘水彩底图。底图不含文字，温室、花境、影院、港口、三座高脚屋、餐车及海浪形成可辨认的小景。北侧预留地保持开阔。手绘透视存在艺术化轮廓，导航坐标仍以实际世界坐标为准。

正式资源 `app/src/assets/ui/island-map-watercolor-v2.webp`，1254×1254，554752 bytes。使用内置 image_gen；完整提示、来源和格式转换记录见同目录 `.prompt.txt`。首次打开时才加载并解码，缓存复用；失败时显示地理数据生成的底图。

## 实际文件
- `app/src/island-map.ts`：单实例地图抽屉、标记、选择目的地、取消、平移缩放、150ms 玩家同步。
- `app/src/island-map.css`：纸张面板、纸签、桌面及手机布局。手机竖屏68dvh、横屏69dvh；按钮≥44px。
- `app/src/island-map-art.ts`：水彩底图懒加载及地理绘图回退。
- `app/src/island-map-model.ts`：统一坐标投影、七个位置与文字。
- `app/src/island-trails-data.ts`、`island-trail-texture.ts`：实际碰撞路径采样与一次性压实痕迹遮罩。
- `app/src/island-surface.ts`：接入原地形、雨雪材质。
- `app/src/navigation-zones.ts`：补充休憩区、餐车两个导航目标。
- `app/src/island-props.ts`：仅移动挡住花园南侧绕行路线的小手推车，由(-7.25,6.85)移至(-10.8,1.4)，保持原朝向，落地高度继续采样地形。
- `app/src/main.ts`：地图与现有玩家位置、sceneVisits、导航目标连接。
- `game/`：生产构建同步。

## 状态与交互
地图不复制任务、种植或存档数据。已发现状态读取已有sceneVisits；步行接近产生的补充发现只在本次会话保存，不扩展存档字段。全岛访问对应港口/高脚屋/餐车，沙滩坐席访问对应影院/休息区。当前目标沿用现有漫游导航，设置目的地只改变导航目标，不传送、不启动剧情。关闭地图不自动锁鼠标。室内标记落在咖啡店，坐席和对话保留玩家位置。

小径为地形材质压实色差，没有道路碰撞、额外灯光或透明贴片，玩家可以自由离开。共享真实天气状态，雨天更深，雪天保留压实色差。路径宽0.88m，大于玩家直径0.54m的1.5倍。沿现有栈道继续前往水上屋。
