# 东侧浅滩 · 三座高脚屋

本次仅增加环境景观，未发布。预览：http://127.0.0.1:5194/。

## 实际选址与保护范围

查阅 `world.ts`、`island-geography.ts`、`beach-ground.ts`、`island-props.ts`、`island-water.ts`、`harbor.ts`、`island-boat.ts`、`main.ts` 与现有相机、沙滩回归记录。户外咖啡座位在 x=3.55、z=0.35/2.8，花园位于负 x 一侧，港口与航道位于南侧 z≈25–31。因此选择正 x（东侧）浅滩。新布局不改原岛轮廓、岸线、庭院、花园、人物、镜头、交互或存档。

房屋 x 坐标由现有渲染地形的东侧水线加离岸距离求得，不重建海岸。最终中心：

| 房屋 | 世界坐标 x / 地板 y / z（米） | 海床高度 | 陈设 |
|---|---|---|---|
| 晨光小屋 | 16.498 / 0.08 / -2.4 | -2.304 | 米白木墙、鼠尾草顶、小椅、陶杯、盆栽 |
| 晾风小屋 | 18.362 / 0.08 / 2.8 | -2.411 | 浅木墙、陶土色顶、晾布、藤篮、麻绳 |
| 渔灯小屋 | 17.757 / 0.08 / 8.4 | -2.241 | 浅灰墙、深灰绿顶、暖灯、渔具、旧木箱 |

海面基准 -1.63 米；屋体约 2.6×2.6 米，另加小露台。屋脊 2.74 米，低于咖啡馆主体。岸端从 (10.25, 6.5) 空白沙面接入，以台阶接到 x=13.35 的窄栈道，三条短支路连接各屋露台。场景中有清晰水面间隔，未进入南侧登岸路径或船只泊位。

手机保持原来的咖啡馆近景，屏幕边缘只露出部分屋群；通过现有「全岛」与环绕操作看完整聚落，没有为容纳屋群擅自拉远默认机位。

## 结构与天气

- 68 根屋体/栈道支撑柱按真实海床采样，柱底埋入 0.26 米；静态桩柱不随波浪漂浮。
- 木板地面、承重横梁与斜撑相接，露台入口和分支标高一致，岸端使用连续台阶。
- 最大水位 +0.4、最大波幅倍率 1.5 时，保守外海波峰高度为 -0.27 米，主要地板底面为 -0.03 米。逐点扫测晴雨雪、水位和波幅后，所有栈道/台阶/露台检查点的最小净空为 **0.2215 米**。
- 潮痕使用同一世界水位的实例化短柱带；桩柱本体不动。
- 雨天木材和织物变深、风摆减弱；雪天屋顶、檐篷、栏杆和水平栈道添加简化雪层，竖面无整片积雪。
- 窗面与门边灯使用共享暖色自发光，随既有暮色值渐变；不新增光源。
- 两盆植物和一段织物轻微错相风摆，无独立计时器、监听器或复杂物理。

## 性能

静态部分按材质合为 16 个批次，雪层 1 批；潮痕实例化。模块共约 22,036 个三角形（桌面）、21,412 个（手机），移动端降低植株细节并关闭新增物件投影。没有逐片花叶 draw call。

同一生产场景、同一 Chrome 会话内，测试工具临时切换新增模块显隐，以 ABBA 顺序采样，每段预热 1.2 秒后采样 120 帧。以下数值包含现有渲染/反射/阴影各 pass；帧耗时列是两轮中位数的均值。

| 平台 | 绘制调用 | 三角形/帧（含各 pass） | 帧耗时 |
|---|---|---|---|
| 1440×900 桌面 | 1704.8 → 1768.4（+3.73%） | 7012048 → 7084716（+1.04%） | 19.90 → 19.65 ms |
| 390×844 手机模拟 | 1563.0 → 1612.7（+3.18%） | 6300483 → 6344885（+0.70%） | 10.00 → 10.00 ms |

未观察到明显帧耗时退化。手机数据为桌面 Chrome 的 390px 触屏模拟，不是实机 GPU 测试。原有场景整体绘制调用仍较多，本次没有扩大重构范围。
