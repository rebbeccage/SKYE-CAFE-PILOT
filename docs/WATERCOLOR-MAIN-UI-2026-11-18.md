# 天空岛 · 主界面水彩 UI

日期：2026-11-18。范围：主界面视觉、导航入口排布与必要的展示控制。没有重构游戏、相机、天气或存档。

## 检查结果与取舍

- 视觉基准为 `concept-art/watercolor-main-ui-kit-concept-v2.png`。只参考布局、色彩和比例；没有把概念图作为背景或裁成按钮。
- 现有主入口为相遇、菜单、装扮、仓库；原“景致”抽屉提供观察控制。种植面板原本只由作物热点等入口打开。
- 按本次要求恢复“花园”主导航入口，但仍调用原 `gardenPanel()`，并保留棠姨第三章的解锁条件。锁定时可读到说明，不能经营；作物热点保持原行为。
- 原人物头像已经是只读人物手记，沿用原水彩画像、姓名、简介和进度。三位主线人物在现有规则中从开始即可相遇，没有独立“人物锁定”状态，因此没有擅自添加锁定门槛或遮蔽可见人物。
- 日签继续使用 `goalPresentation()` / `nextGoal()`，余额为 `save.coins`。日期与分钟为现有设备本地生活时钟，不能改变日光/暮色；没有新增日期或进度存档。
- 当前目标为二元条件时仍显示阶段文字、隐藏进度条；故事章数及作物生长才显示真实数值进度。

## 实际实现

1. 六项导航按相遇、菜单、仓库、装扮、花园、随心逛逛排列。桌面左下分离纸片；手机横向滑动，热区大于 44px。
2. 左上小型天气标签、顶部庭院/店内、右上日签与相遇头像，保持中央场景清空。声音与帮助在屏幕边缘保留独立入口。
3. “随心逛逛”继续使用原 details 抽屉与原控制元素，包含环绕、归位、全岛、花园近景、日光/暮色、留影。内部 id 和操作接口不变。
4. 主导航用共享透明水彩图集。桌面图标 64px，手机约 42px；人物头像由 52px → 72px、手机 42px → 58px，窄屏/横屏按可用空间缩减。
5. 手机日签默认显示余额、小时分钟与任务摘要，44px 展开控制显示完整日期、阶段和真实进度。头像栏根据日签实际高度排布，避免展开或提示切换时重叠。
6. 图标、导航按钮、头像徽章、任务进度条共用 `ui-components.ts` 展示工厂；纸片、选中、锁定、禁用、新叶片、hover 与 pressed 状态集中在 `watercolor-ui.css`。
7. 动画为 200ms 轻移和颜色过渡；减少动态效果模式下关闭。没有全屏模糊、发光脉冲或持续粒子。
8. 既有对话、人物卡和菜单仍用原模态窗口锁定场景。工具抽屉移至功能栏，展开层脱离滚动裁剪；点空白处关闭。原场景提示继续自动消失及去重；制作时，入场提示、制作进度和临时文字反馈分别排布，避免互相覆盖。

## 验证方法

- `npm run build`：TypeScript 检查、Vite 生产构建。
- `node verification/watercolor-protected.cjs`：与修改前哈希比较，50 个未授权改动的场景、玩法、存档、对话、音频及样式模块逐字节不变。
- `node verification/watercolor-ui-playtest.cjs`：真实 Chrome 中桌面 1440×900、手机 390×844、横屏 844×390，验证六入口、头像展示卡、手机任务展开、布局面积/重叠/热点、天气、暮色、店内、解锁花园及减少动态效果。
- `node verification/watercolor-regression.cjs`：执行当前有效的状态测试与浏览器回归。完整结果见 `verification/watercolor-ui/regression-results.json` 和各测试日志。
- 测试仅在独立浏览器上下文中使用模拟存档，不读取或覆盖用户当前浏览器进度。截图中的金币来自该测试存档，UI 没有写死余额。

既有测试的契约适配：仓库测试的“主页无花园按钮”更新为本次要求的“有锁定花园入口”；HUD 占屏阈值由旧 20% 调整为本次 25%，避免重复计算嵌入底栏的工具抽屉；HUD 单元测试解析新增纯展示组件；场景提示测试在同一帧读取提示及对应的 DOM 隐藏状态，避免 7 秒自动隐藏计时跨帧造成误判。

初轮边构建边测试产生过旧哈希资源 404，之后固定构建串行测试。界面修复包括旧 `.game-nav span` 对工具文字的隐藏、手机占屏面积超限、头像跟随日签高度，以及旧店内样式导致横屏声音工具区拉宽遮挡场景切换按钮。本轮不对未改动的场景效果重复进行性能基准；只增加一个约 323KiB 的共享 WebP 和 DOM/CSS，不增加 Three.js 绘制调用或新实时光源。
